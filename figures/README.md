# Figures

Figures are derived from the machine-readable artifacts under `experiments/`.

- `alignment/` contains the existing four-seed GRPO validation comparison.
- `training/` contains the completed TinyStories train/validation loss curve.
- `systems/`, `scaling/`, and `data_pipeline/` are reserved for plots generated from the committed CSV/JSON summaries.

Do not edit result figures independently of their source data.
